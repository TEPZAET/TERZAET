# TERZAET

TERZAET помогает подключиться к своему VPN-серверу. Сервер настраивается с телефона, а для каждого человека можно создать отдельный ключ доступа.

Настройка простая: укажите данные VDS, выберите протокол и нажмите кнопку установки. Приложение само проверит сервер и подготовит его. Вручную вводить команды не нужно.

Режим «Яндекс Документы» может помочь подключиться в российских сетях с «белыми списками», если Яндекс Документы в этой сети доступны. Соединение проходит через этот сервис, поэтому иногда работает там, где обычное VPN-подключение не проходит. Результат зависит от оператора и текущих ограничений, поэтому гарантировать работу в каждой сети я не могу (

## Перед началом

### 1. Создайте VDS

VDS, или виртуальный сервер, можно арендовать у любого облачного провайдера, лучше всего подойдет зарубежный для работы всех сервисов. В панели провайдера нажмите создание сервера и выберите Linux, например Ubuntu. Нужен сервер с публичным IP-адресом.

После создания откройте страницу этого сервера в панели провайдера. Там обычно указаны:

- **IP-адрес**. Например, `203.0.113.10`. Это адрес сервера, а не адрес телефона.
- **Логин для SSH**. Часто это `root`, но провайдер может указать другой.
- **Пароль для SSH**. Он может прийти в письме или показываться в панели провайдера. Если пароль не задан, задайте его там.
- **SSH-порт**. Обычно `22`. Если провайдер указал другой порт, используйте его.

Сохраните эти данные: приложение спросит их при установке. Не отправляйте пароль и ключи доступа другим людям, данные сохранит только локально.

Установка из приложения подключается по паролю SSH. Если провайдер настроил вход только по SSH-ключу, этот способ установки не подойдёт, пока что.

### 2. Решите, какие протоколы установить

В приложении можно установить Hysteria 2, «Яндекс Документы» или оба протокола.

- Для Hysteria 2 ничего заранее готовить не нужно. Если у провайдера есть сетевой экран, в его панели разрешите входящий UDP-порт `443` (скорее всего это делать не прийдется).
- Для «Яндекс Документы» сначала создайте пустой документ в Яндекс Документах. Нажмите **Поделиться**, включите доступ **По ссылке** и выберите право **Редактирование**. Скопируйте ссылку: она понадобится при установке.

Если выбираете только Hysteria 2, документ Яндекса не нужен.

## Установка на телефон и сервер

1. Скачайте приложение со [страницы релиза TERZAET](https://github.com/TEPZAET/TERZAET/releases/tag/v2.0.0) и установите APK на Android-телефон, IOS будет но не скоро.
2. Откройте в приложении вкладку **Серверы** и нажмите **Добавить сервер**.
3. Введите название, IP-адрес, логин, пароль и порт из панели провайдера. Если порт не указан, оставьте `22`.
4. Нажмите **Далее**. Приложение проверит соединение с сервером и покажет следующий шаг.
5. Выберите нужные протоколы. Если включили «Яндекс Документы», вставьте ссылку на документ. Hysteria 2 можно включить отдельно или вместе с ним.
6. Нажмите кнопку установки и дождитесь сообщения **Сервер настроен**. Во время установки не закрывайте приложение и не выключайте интернет.

Приложение сохранит SSH-пароль на этом телефоне в зашифрованном виде. Он нужен для управления сервером и не является ключом подключения для других пользователей.

## Создание ключа для пользователя

1. На вкладке **Серверы** нажмите на установленный сервер.
2. Откройте **Пользователи и ключи**, затем нажмите **Добавить пользователя**.
3. Введите имя и выберите протоколы, которые будут доступны этому человеку.
4. Нажмите **Создать ключ доступа**. На следующем экране появятся ключ и QR-код.
5. Передайте человеку строку ключа или QR-код. Они дают доступ к серверу, поэтому отправляйте их только тому, кому доверяете.

## Подключение по ключу

На телефоне пользователя:

1. Нажмите на главном экране **Добавить** и вставьте ключ TERZAET. Если ключ передали QR-кодом, нажмите **Снимок** и наведите камеру на код.
2. Выберите добавленную конфигурацию на главном экране.
3. Нажмите кнопку подключения.

Если соединение не запускается, проверьте, что сервер включён, а для Hysteria 2 разрешён UDP-порт `443` в панели провайдера.

## Ручная установка

Если вы устанавливаете сервер не из приложения, подключитесь к VDS по SSH и выполните команду от имени администратора:

```bash
export TERZAET_DOC_URL='https://disk.yandex.ru/i/...'
curl -fsSL https://raw.githubusercontent.com/TEPZAET/TERZAET/main/server/scripts/install-terzaet.sh | sudo -E sh
```

Для этого способа нужна ссылка на документ Яндекса. Установка только Hysteria 2 выполняется из приложения.

## О проекте

TERZAET основан на [OpenFluxAndroid](https://github.com/p1neappleXpress/OpenFluxAndroid) и [OpenFlux](https://github.com/p1neappleXpress/OpenFlux). Это независимый проект, не связанный с авторами оригинальных репозиториев. Компоненты и сторонний код принадлежат их авторам. Программа предоставляется как есть.
